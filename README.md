# 🍽️ Aura Eats — Elevated Dining

> Crave the extraordinary.

Aura Eats is a premium food-ordering web experience designed to make
discovering and exploring food feel elegant, interactive, and effortless.

## ✨ Features

- 🍴 Interactive food menu
- 🛒 Shopping cart experience
- 📱 Responsive design
- 🎨 Premium modern UI
- ⚡ Fast Vite-powered frontend
- 🔍 Easy menu exploration
- 📦 Order/checkout flow

## 🛠️ Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
